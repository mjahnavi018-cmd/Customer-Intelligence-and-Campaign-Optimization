## 1. iFood CRM Data Analyst case ("marketing campaign" dataset)

| Item | Detail |
|---|---|
| Dataset name | iFood Brain team Data Analyst case — `ml_project1_data.csv` |
| Source organisation | iFood (Brazilian food-delivery company) hiring case, published by Nailson Boaz; widely mirrored on Kaggle as *Customer Personality Analysis* (imakash3011) |
| URL | https://github.com/nailson/ifood-data-business-analyst-test |
| Download URL | https://github.com/nailson/ifood-data-business-analyst-test/blob/master/ml_project1_data.csv ("Download raw file") |
| Date accessed | 2026-09-11 |
| License | The GitHub repository contains **no license file**. The Kaggle mirror is labelled CC0; its provenance is this repository. Treated as *not redistributable* here. |
| Rows × columns | 2,240 × 29 (2,019 customers after cleaning) |
| Time coverage | customer enrolment 2012-07-30 → 2014-06-29; spend = "last 2 years" before an undocumented snapshot date |
| Relevant variables | demographics (Year_Birth, Education, Marital_Status, Income, Kidhome, Teenhome), Dt_Customer, Recency, Mnt* (6 categories), Num*Purchases (web/catalog/store/deals), NumWebVisitsMonth, AcceptedCmp1–5, Response (pilot), Complain, Z_CostContact (=3), Z_Revenue (=11) |
| Data dictionary | `dictionary.png` in the repository; the case PDF states the pilot: 2,240 customers contacted, cost 6,720 MU, revenue 3,674 MU, profit −3,046 MU, success rate 15 % (consistent with 3 MU/contact and 11 MU/response) |
| Intended use here | customer value, RFM/segmentation, campaign × segment, purchase channels, response prediction, pilot economics, targeting, budget allocation |
| Limitations | single snapshot; no transaction/campaign dates; campaign delivery channel & C1–C5 exposure/cost unknown; duplicates; recency almost uniform (possible synthetic/curated data); snapshot likely taken after the pilot |
| Real / synthetic | Presented as a company hiring case; **provenance not documented** — may be anonymised and/or partly synthetic. Results describe this dataset, not a verified real population. |
| Preprocessing | see `src/preprocessing.py` and `reports/data_audit.md` (label normalisation, de-duplication, invalid values → NaN + flags, constants → economics parameters) |
| Integrity | file used: 2,241 lines incl. header; SHA-256 of the exact text content downloaded `674bba0f…c919` (line-ending differences change the file hash; the loader validates schema and row count instead) |

## 2. Kevin Hillstrom — MineThatData E-Mail Analytics and Data Mining Challenge (2008)

| Item | Detail |
|---|---|
| Dataset name | `Kevin_Hillstrom_MineThatData_E-MailAnalytics_DataMiningChallenge_2008.03.20.csv` |
| Source organisation | Kevin Hillstrom, MineThatData (challenge post: https://blog.minethatdata.com/2008/03/minethatdata-e-mail-analytics-and-data.html) |
| URL / mirror used | https://github.com/bscan/uplift (MIT-licensed repository that includes the original CSV; the MIT license covers that repository's code, not necessarily the data) |
| Download URL | https://github.com/bscan/uplift/blob/master/Kevin_Hillstrom_MineThatData_E-MailAnalytics_DataMiningChallenge_2008.03.20.csv ("Download raw file") |
| Date accessed | 2026-09-11 |
| License | Released publicly for the 2008 challenge; **no explicit license** → not redistributed here |
| Rows × columns | 64,000 × 12 |
| Time coverage | customers who purchased in the prior 12 months; outcomes tracked for 2 weeks after the e-mail (2008) |
| Relevant variables | recency (months), history_segment, history ($), mens, womens, zip_code, newbie, channel, segment (treatment), visit, conversion, spend |
| Intended use here | incremental (causal) response, campaign-type choice by customer type, uplift vs response ranking, policy evaluation |
| Limitations | different company & era from iFood; no costs; spend is revenue, not margin; conversions rare (0.9 %) |
| Real / synthetic | real customers of a US retailer as described by the author; anonymised (no IDs) |
| Preprocessing | `Surburban` → `Suburban`; derived treatment label, history band, recency band, buyer type; no rows removed |
| Integrity | SHA-256 `0e5893329d8b93cefecc571777672028290ab69865718020c78c7284f291aece`, 64,001 lines incl. header |
